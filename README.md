# Fully-Functional-Calculator
A responsive and fully functional calculator built using HTML, CSS, and JavaScript that performs basic arithmetic operations with a clean, modern interface and real-time expression evaluation.

# Description
This project is a fully functional web-based calculator developed using HTML, CSS, and JavaScript. It provides a clean, responsive, and user-friendly interface capable of performing basic arithmetic operations with real-time input handling. The calculator features a modern glassmorphism-inspired design, interactive buttons, and dynamic expression evaluation through JavaScript. It is designed to demonstrate fundamental front-end development concepts, including DOM manipulation, event handling, and responsive UI design.

# Features
Perform basic arithmetic operations (+, −, ×, ÷)
Percentage (%) calculation support
Decimal number calculations
Double zero (00) input
All Clear (AC) functionality
Delete (DE) functionality for removing the last entered character
Real-time display updates
Responsive and modern calculator interface
Interactive button click events
Simple and lightweight implementation
# Technologies Used

# Project Overview

The calculator is built using a modular structure where HTML defines the user interface, CSS provides the visual styling, and JavaScript manages all calculator operations. User interactions are captured through button click events, and mathematical expressions are evaluated dynamically. The interface includes numeric keys, arithmetic operators, percentage calculation, clear and delete functions, and an output display for real-time results.

# Key Functionalities
Displays user input dynamically.
Supports addition, subtraction, multiplication, division, and percentage operations.
Clears the entire expression using the AC button.
Removes the most recent character using the DE button.
Evaluates expressions instantly when the = button is pressed.
Provides a clean and intuitive user experience with responsive styling.
